API

The app reads from this API. It only supports GET. Call it with Postman at this base URL:

https://bingjiang.github.io/practicenest/api/v1

GET /viewings/page/{n}.json

Your viewings, 4 per page, from page 1. total is the number of viewings across all pages. start and end are in UTC.

{
  "page": 1, "pageSize": 4, "total": 1,
  "results": [
    { "id": "V-0000", "listingId": "L-000", "agentId": "A1",
      "start": "2026-10-01T06:00:00Z", "end": "2026-10-01T06:30:00Z",
      "status": "pending" }
  ]
}

status is one of pending, confirmed, cancelled or completed.

GET /listings/{id}.json

One listing. maintenanceFeeSgd is the monthly fee, or null when the seller hasn't provided it.

{
  "id": "L-000", "title": "…", "type": "Condo", "district": "…",
  "price": 1000000, "bedrooms": 2, "bathrooms": 2,
  "floorAreaSqft": 800, "floorAreaSqm": 74.3, "psf": 1250,
  "maintenanceFeeSgd": 300, "listedOn": "2026-09-01", "agentId": "A1"
}
